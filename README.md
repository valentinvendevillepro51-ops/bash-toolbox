# bash-toolbox

Scripts Bash pour automatiser des tâches sous Linux (sauvegarde, rapport système).

Petite collection de scripts écrits sous Ubuntu pour apprendre le shell et
l'automatisation. Projet personnel en cours de réalisation pendant ma
1re année de bachelor informatique (ESGI).
